# Venom module: Rider-Pi

Optional Venom extension for operating Rider-Pi as Venom's mobile eyes, ears and physical executor.

## Product direction

- Manual controls, camera preview, STOP and device calibration are the primary operator interface.
- Rider-Pi owns hardware, motion execution, calibration, profiles and local safeguards.
- Venom provides the shared compute, models, voice, knowledge and orchestration.
- Robot controls through Venom's existing chats and voice are optional.
- Use Venom's existing optional-module architecture, as used by Brand Studio.

## Repository status

R1 development: the optional router, shared Pi client, demand-driven observations and hardware-free acceptance fixture are implemented locally. The operator UI and complete local acceptance are being integrated. No physical robot operation has been validated by these tests.

Business logic belongs in this repository. Venom core supplies the host and shared services. Local development uses the existing Venom environment; do not install dependencies globally or copy the complete Rider-PC AI stack.

Implementation and release instructions will accompany working code. Local plans, device addresses, credentials and session reports are not published.
